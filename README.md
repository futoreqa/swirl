# Swirl

Круговое меню для файлов в Windows (раньше называлось Shiftr). Начните тащить файл в Проводнике, нажмите **Shift**, и у курсора появится кольцо. Бросьте файл на сектор, и готово.

**[⬇ Скачать SwirlSetup.exe](https://github.com/futoreqa/swirl/releases/latest/download/SwirlSetup.exe)**: установка за один клик, без прав администратора и без .NET. Обновляется сама.

## Что умеет

- **Картинки.** PNG, JPG, WEBP, ICO, PDF, GIF, BMP, TIFF; качество и размер в подменю; удаление фона нейросетью (офлайн).
- **Видео и звук.** MP4, WEBM, GIF, MOV, MKV, MP3, WAV, OGG, FLAC, M4A, OPUS; «Под размер» 10/25/50 МБ для Discord и Telegram; обрезка; склейка нескольких роликов или треков.
- **PDF.** В Word и в текст (сканы распознаются встроенным OCR Windows), в картинки; сжать, склеить, разбить, поставить пароль.
- **Офис.** Word → PDF; CSV → Excel без Office; Excel → PDF, CSV, JSON; каждый лист → отдельный CSV; несколько CSV → одна таблица; PowerPoint → PDF или слайды в PNG; Markdown, HTML, TXT → PDF.
- **Файлы.** Распаковка ZIP/7Z/RAR/TAR/GZ, ZIP с паролем (AES-256), SHA-256 и сравнение, поиск дубликатов с удалением, перемещением или переименованием, ссылка на файл, пакетное переименование.
- **SVG.** SVG → PNG/JPG/WEBP любого размера и картинка → SVG (трассировка: 4, 8 или 16 цветов).
- **Буфер обмена.** Правый клик на папке → «Вставить из буфера (Swirl)»: скриншот → PNG, таблица из Excel → XLSX, текст → TXT.
- **Без перетаскивания.** Выделите файлы и нажмите Ctrl+Shift+Space (сочетание меняется) — кольцо появится у курсора.
- **English.** Интерфейс на русском и английском.
- **Удобство.** Пресеты, волшебные папки, история с отменой, пункт в меню правой кнопки, понятные сообщения об ошибках.

ffmpeg и модель для удаления фона скачиваются сами при первой необходимости.
