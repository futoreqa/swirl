# Shiftr

Круговое меню для файлов в Windows. Начните тащить файл в Проводнике, нажмите **Shift**, и у курсора появится меню. Бросьте файл на сектор, и он сконвертируется.

**[⬇ Скачать ShiftrSetup.exe](https://github.com/futoreqa/shiftr/releases/latest/download/ShiftrSetup.exe)**: установка за один клик, без прав администратора и без .NET. Обновляется сама.

## Что умеет

- **Конвертация.** PNG, JPG, WEBP, ICO, PDF, GIF, BMP, TIFF. MP4, WEBM, GIF, MOV, MKV, MP3, WAV, OGG, FLAC, M4A, OPUS. PDF → PNG/JPG. Подменю с качеством и размером: 1080p, 720p, 1920px, «Лёгкий» и другие.
- **«Под размер».** Ужимает видео до 10, 25 или 50 МБ для Discord и Telegram.
- **Быстрые действия.** Сжать, убрать фон (нейросеть, работает офлайн), обрезать, уменьшить вдвое, повернуть, склеить или разбить PDF, убрать звук, вытащить кадр, удалить EXIF, выровнять громкость, скопировать в буфер, сделать ссылку на файл, переименовать пачкой, упаковать в ZIP.
- **Пресеты.** Свои секторы: формат, качество и размер.
- **Волшебные папки.** Всё новое, что попадает в папку, конвертируется само.
- **История с отменой.** Созданные файлы уходят в корзину, переименования откатываются.
- **Меню правой кнопки.** Пункт «Shiftr…» открывает то же меню по клику.

ffmpeg и модель для удаления фона скачиваются сами при первой необходимости.
