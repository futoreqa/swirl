How it works

Drag. Shift. Drop.

No windows, no ten-item menus. The ring picks the right actions for each file type.

  1. Drag a fileFrom Explorer, the desktop or any folder.
  2. Press ShiftA ring opens at your cursor: actions inside, formats outside.
  3. Drop it on a sliceThe result lands next to the original. Changed your mind? Undo it from history.
Features

Everything you do with files. In one ring.

Conversion, editing, screenshots, archives and clipboard — no browser, no uploads, no subscription.

Conversion

Images, video, audio and documents. Drop on a format, get a file.

  • PNG · JPG · WEBP · ICO · SVG · HEIC
  • MP4 · WEBM · GIF · MOV
  • MP3 · WAV · OGG · FLAC
  • PDF ↔ Word, text, images
  • Word, Excel, PowerPoint → PDF
  • CSV → Excel

Photo editor

Crop, rotate, brightness, arrows, boxes, text. “Blur it out” hides plates, faces and passwords.

  • 1:1 · 4:5 · 16:9
  • Batch crop
  • Offline AI background removal

Screen

Capture a region or a window — straight to the clipboard and into the ring. Plus recording, a color picker and OCR.

  • Ctrl+Alt+S screenshot
  • Ctrl+Alt+R record MP4/GIF
  • Ctrl+Alt+C HEX picker
  • “Text” — OCR
